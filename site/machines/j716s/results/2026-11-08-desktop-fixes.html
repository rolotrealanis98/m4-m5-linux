Terminals on the native GL driver #

The native Gallium driver cannot build Alacritty's fragment program (the text shader's uniform layout puts a sysval range at an odd uniform half, and the M5 program builder only accepts dword-aligned ranges). Native GL stays the A/B variant; the analysis, fixes (native patches 0006-0008) and an A/B plan for a second tree are in the native GL issue.

Package fill #

Two packages that Omarchy's shell needs were not pulled in by Omarchy's own dependencies on this aarch64 root: imagemagick (wallpaper size) and qt6-imageformats (the Qt webp plugin; the wallpaper layer was blank without it, fixed 2026-11-07). Both were installed by hand; the dependency lists are an upstream packaging item.
